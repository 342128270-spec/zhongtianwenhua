## 核实方式

- 开源项目：GitHub REST API 拉取 stars / license / pushed_at / archived
- Marketplace：GitHub GraphQL marketplaceListings 分页
- 全部脚本采集，无人工录入；日期 2026-11-24

## 边界

收录不等于推荐。安装 Marketplace 应用会授予其对仓库的读写权限，务必先看清权限范围。

数据为快照，星标与维护状态会随时间变化。
