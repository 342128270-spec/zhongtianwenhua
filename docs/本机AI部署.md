## 怎么起步

| 目标 | 路线 |
|---|---|
| 最快跑起来 | llamafile：下载单个文件，双击就能对话 |
| 想要完整参数界面 | text-generation-webui，模型加载、采样参数全暴露 |
| 语音转文字 | whisper.cpp，CPU 也能跑，Mac 上开 Metal 加速更快 |
| 做私有知识库 | 文档切片 → 向量化 → 存 Chroma 或 Qdrant → 检索拼上下文 |

## 风险与边界

1. 本机跑模型**吃内存与显存**：7B 量化模型约需 6–8GB，13B 需 12GB 以上。
2. 量化会损失精度，**法律、医疗、财务结论不要直接采信小模型输出**。
3. 模型权重有许可证差异，商用前确认（如 Llama 系列有用户规模条款）。
