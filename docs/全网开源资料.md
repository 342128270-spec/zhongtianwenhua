## 收录标准

- 仓库未归档（archived = false）
- 近期有代码推送，已停更的不收
- 仅收可自建或本地运行的，不依赖某家云服务才能用
- 星标低于 300 的细分项目不纳入，避免清单变成收藏夹

## 数据来源

脚本调用 GitHub REST API（带令牌认证，避免限流）逐条拉取：

| 字段 | API 路径 |
|---|---|
| 星标 | repos/{owner}/{repo}.stargazers_count |
| 许可 | repos/{owner}/{repo}.license.spdx_id |
| 更新 | repos/{owner}/{repo}.pushed_at |
| 归档 | repos/{owner}/{repo}.archived |
