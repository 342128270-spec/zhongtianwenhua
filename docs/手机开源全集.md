## 十一、iOS 上怎么装

三条路径，从易到难：

1. App Store 直接装 —— VLC、Firefox、Bitwarden、Nextcloud、Signal、Joplin、Immich、Organic Maps、Tailscale 都有官方上架版本。
2. TestFlight 测试版 —— 部分项目（如 Thunderbird iOS）通过测试版分发，需要开发者邀请链接。
3. 侧载 —— 用 AltStore / SideStore 以 Apple ID 签名安装 ipa：
   - 免费账号签名 7 天过期，需要定期重签
   - 首次安装需要一台电脑
   - 每个账号同时最多 3 个侧载应用
   - TrollStore 是例外，靠系统漏洞永久签名，但只支持特定 iOS 版本

| 目标 | 结果 |
