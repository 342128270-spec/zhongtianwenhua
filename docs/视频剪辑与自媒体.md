## 怎么起步

| 目标 | 路线 |

| 日常剪辑 | Shotcut 足够，占用低 |
| 多轨复杂项目 | Kdenlive，工程管理更完整 |
| 只要剪掉头尾 | LosslessCut，不重新编码，几秒完成 |
| 做字幕 | SubtitleEdit 对齐时间轴，配合 whisper.cpp 自动生成初稿 |

## 风险与边界

1. **版权是自媒体的第一风险。** 背景音乐、影视片段、他人素材，未获授权即商用，平台与权利人都会追责。
2. yt-dlp 下载内容仅限个人备份与合理使用，**不得用于二次分发**。
3. AI 配音、AI 换脸需标注，部分平台要求显著标识，隐瞒可能被限流或封号。
