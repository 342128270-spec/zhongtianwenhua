## data/all.json 字段

| 字段 | 类型 | 含义 |
|---|---|---|
| name | string | 显示名称 |
| id | string | 仓库全名 owner/repo，或 Marketplace slug |
| desc | string | 简介 |
| category | string | 分类 |
| source | string | 开源项目 / Marketplace |
| doc | string | 出自哪份文档 |
| stars | string | 星标（仅开源项目） |
| license | string | 许可证（仅开源项目） |
| updated | string | 最近推送年月 |
| link | string | 原始链接 |
| paid | string | 付费 / 免费（仅 Marketplace） |
| verified | bool | 是否官方验证（仅 Marketplace） |

## 怎么用这份数据（jq 示例）

    # 统计某分类
    jq "[.[] | select(.category==\"Security\")] | length" data/all.json

    # 列出所有 AGPL 项目
    jq -r ".[] | select(.license==\"AGPL-3.0\") | .id" data/all.json

    # 只列 Marketplace 付费应用
    jq -r ".[] | select(.source==\"Marketplace\" and .paid==\"付费\") | .name" data/all.json

## 数据来源与核实方式

- 开源项目：GitHub REST API 逐条核实星标、许可证、推送时间、归档状态。
- Marketplace：GitHub GraphQL API 的 marketplaceListings 分页拉取。
- 所有条目均为脚本采集，非人工录入；核实时间 2026-11-24。
