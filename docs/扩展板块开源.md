## 怎么起步

| 你想做的事 | 路线 |
|---|---|
| 学科学计算 | NumPy 打底 → SciPy 补工具 → Matplotlib 出图 → Jupyter 串起来 |
| 做仿真 | 流体用 OpenFOAM，分子用 GROMACS，先跑官方算例再改 |
| 第一次做游戏 | Godot 或 LÖVE，一周能出可玩 demo |
| 做 2D 网页游戏 | Phaser，浏览器直接跑 |
| 碰智能合约 | Solidity + Foundry，先在测试网练手 |
| 只想理解区块链 | 读 bitcoin/bitcoin 的源码，比看一百篇文章有用 |
| 做智能家居 | ESPHome 刷设备 → MQTT → Node-RED 编排 |

## 风险与合规

1. **区块链相关在中国境内有明确监管边界。** 虚拟货币交易、代币发行融资、挖矿等业务被明令禁止；本清单仅作技术资料索引，不构成任何投资或经营建议。
2. **智能合约一旦部署无法修改。** 先在测试网跑，审计后再上主网，别拿真钱试错。
3. **物联网设备是常见攻击入口。** 默认密码、暴露到公网的 MQTT、未加密的固件升级，都是真实发生过的入侵路径。接入前先隔离到独立 VLAN。
4. **科学计算的结果依赖前提假设。** 仿真跑出曲线不等于物理正确，先做网格无关性验证与实验对照。
