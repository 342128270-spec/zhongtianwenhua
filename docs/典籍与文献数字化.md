## 怎么起步

| 目标 | 路线 |
|---|---|
| 扫描件转可搜索 PDF | OCRmyPDF 一把梭，中文加 --language chi_sim |
| 古籍影印，繁体竖排 | PaddleOCR 的版面分析更稳，能识别竖排 |
| PDF 里公式表格要保留 | docling 或 marker，输出 Markdown 更好二次处理 |
| 想要可检索的诗词语料 | chinese-poetry，直接拿 JSON |

## 风险与边界

1. OCR 有错字率，**重要典籍必须人工校对**，不能直接当善本用。
2. 古籍异体字、避讳字非常多，模型默认词表识别不了，需要自定义字库。
3. 版权：民国以前的作品已进入公有领域，但**现代点校本、影印本有版权**，扫描传播需谨慎。
