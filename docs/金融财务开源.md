## 三条路线，按目的选

| 你的目的 | 建议路径 |
|---|---|
| 学量化、跑回测 | backtrader 上手 → qlib 做因子研究 → Lean 上实盘 |
| 只做加密 | freqtrade 或 jesse，文档和社区最完整 |
| 只要 A 股数据 | akshare（免费、中文文档全） |
| 个人记账、想数据归自己 | beancount（纯文本）或 firefly-iii（有界面） |
| 小公司要一套正经账 | ERPNext 或 Odoo，别自己写 |
| 只想要报表看数据 | OpenBB 做研究面板 |

## 风险与合规（务必读）

1. **回测不等于实盘。** 过拟合、幸存者偏差、滑点与手续费漏算，是散户亏钱的前三大来源。任何"年化 XX%"的回测结果，先看它有没有扣成本、有没有做样本外验证。
2. **杠杆与合约可以让你归零。** 开源框架不限制你的仓位，风控要自己写。
3. **在中国境内，证券投资咨询与代客理财需要牌照。** 用这些工具做自己的交易没问题，拿别人的钱去做、或对外提供买卖建议收费，属于违规甚至违法。
4. **加密货币相关工具在境内不受法律保护。** 交易、兑换、撮合业务均被明令禁止，本清单仅作技术资料索引。
5. **税务与会计准则因地区而异。** ERPNext / Odoo 的科目表是通用模板，实际使用需按当地准则调整，不要直接拿去报税。
